# Quick Sort

## 解題說明

本題要求實現一個快速排序法，以最好的時間/空間複雜度去排序和計算出所耗費時間，還有跟最差的情況去做比較。

### 解題策略

1. 使用median-of-three method來完成快速排序法。

2. 計算運行時間使用 clock( ) 測量排序時間。

3. 比較排序資料所需的時間。
